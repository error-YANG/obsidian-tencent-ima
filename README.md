# IMA 知识库同步（Obsidian ↔ 腾讯）

<p align="center">
  <b>Obsidian ↔ 腾讯 IMA 知识库 双向同步插件</b><br>
  通过 IMA 官方 OpenAPI，把 Obsidian 笔记与 IMA 知识库自动对齐
</p>

---

## ✨ 功能特性

### 📤 上传（Obsidian → IMA）

- **增量推送**：基于正文 hash 记账，内容没变不重传，省流量省时间
- **自动补传**：每次推送前批量核验服务端（50 个/批），你在 IMA 端删过的文件自动重新上传，无需手动清账本
- **同名自动编号**：IMA 官方 API 无更新/覆盖接口，远端同名被占用时自动编号为 `A(1).md`、`A(2).md`，旧版保留（即天然版本管理）
- **目录白名单**：只上传白名单目录下的 `.md`，一个目录一行

### 📥 拉取（IMA → Obsidian）

- 把源知识库根目录的 `.md` 笔记拉回本地指定文件夹（不存在自动创建）
- **冲突保护**：本地同名且内容相同 → 跳过；同名但内容不同 → 跳过并报告冲突，**绝不覆盖本地修改**
- 当前仅处理知识库根目录，子文件夹不递归；仅支持 `.md`（media_type=7）

### 🔄 双向同步

- 按传输策略串行执行两个方向：**先上传再拉取**（默认）或**先拉取再上传**
- 左侧竖栏「杨」字图标 / 右下角状态栏 `杨 ⇅` 按钮，**点一下全对齐**
- 运行中显示进度条 + 百分比 + 当前文件名，结束显示绿/红汇总 6 秒自动收起

### 🛡️ 稳定性设计

- 运行锁防并发（上传/拉取/同步互不打架）
- 服务端校验接口异常时自动降级为纯本地增量，不会卡死推送
- 前置校验齐全：未配 Key、白名单为空、未选知识库都会给出明确 Notice 提示

## 📦 安装

> 本插件未上架官方市场，需手动安装（或通过 BRAT 等社区方式）。

1. 下载 `main.js`、`manifest.json` 两个文件
2. 放到你的库目录：`<vault>/.obsidian/plugins/ima-push/`
3. Obsidian 设置 → 第三方插件 → 启用 **IMA 知识库同步**

## 🔑 获取 IMA OpenAPI 凭据

1. 前往腾讯 IMA 官方渠道申请 OpenAPI 的 **Client ID** 与 **API Key**
2. 插件设置页填入，点「测试连接」验证，再点「刷新知识库列表」拉取你有写入权限的知识库

## ⚙️ 配置说明

| 配置项 | 说明 |
|--------|------|
| Client ID / API Key | IMA OpenAPI 凭据，本地保存在 `data.json`，不会上传任何第三方 |
| 测试连接 | 验证凭据并顺带拉取知识库列表 |
| 刷新知识库列表 | 一键拉取当前 Key 有写入权限的全部知识库，供下拉框共用 |
| 传输规则 | 双向行为的完整说明（见设置页） |
| 远程目录（上传） | 白名单笔记全部上传到这个知识库 |
| OB 端目录白名单 | vault 内文件夹名，一行一个，如 `【31-ZABBIX】` |
| 远程目录IMA（拉取） | 从这个知识库拉取 .md 到本地 |
| 本地落地目录 | 拉取的笔记存放的 vault 文件夹，留空 = 根目录 |
| 传输策略 | 双向同步的执行顺序，默认先上传再拉取 |

## 🖱️ 使用方式

| 入口 | 位置 | 行为 |
|------|------|------|
| 「杨」字图标 | 左侧竖栏 | 双向同步（按传输策略） |
| `杨 ⇅` 按钮 | 右下角状态栏 | 双向同步（按传输策略） |
| 命令面板 `Ctrl+P` | — | Push now / Push current note / Force re-push all / Pull from IMA / Sync |

**日常口诀：写完笔记（或删了文件）→ 点一下图标 → 两边自动对齐。**

## ⚠️ 能力边界（务必了解）

1. **IMA 官方 API 没有「更新/覆盖已入库文件」的接口**——修改笔记后再推送，IMA 端会新增 `A(1).md` 版本，旧版保留；想要干净覆盖：先去 IMA 端删旧版 → 再推送
2. 拉取仅支持 `.md`，PDF/Word 等格式不会拉取
3. 仅处理知识库根目录，子文件夹不递归
4. 插件 id / 目录名为 `ima-push`，请勿中途改名（会丢失本地账本配置）

## 🔧 技术实现

- 鉴权：`ima-openapi-clientid` / `ima-openapi-apikey` / `ima-openapi-ctx` 请求头
- 上传链：`create_media`（获取 STS 临时凭证）→ 腾讯云 COS v5 签名直传（HMAC-SHA1）→ `add_knowledge` 入库
- 增量：本地 `fileStates` 账本记录每篇 pushHash / kbId / mediaId
- 服务端存在性校验：`check_repeated_names` 批量核对（50 个/批），`is_repeated=false` 视为远端已删除 → 自动补传
- 拉取链：`get_knowledge_list`（游标分页）→ `get_media_info`（签名 URL + 专用 headers）→ 带头 GET 下载原文
