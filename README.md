# IMA 知识库同步（Obsidian ↔ 腾讯）

<p align="center">
  <b>Obsidian ↔ 腾讯 IMA 知识库 双向同步插件</b><br>
  通过 IMA 官方 OpenAPI，把 Obsidian 笔记与 IMA 知识库自动对齐
</p>

---

> **⚠️ 免责声明**：本项目为个人开发的第三方工具，通过腾讯 IMA OpenAPI 交互——该接口非官方公开契约，兼容性可能随官方调整。插件**不内置任何凭据**，需用户自行申请 Client ID / API Key，凭据仅保存在本地 `data.json`，不会上传到任何第三方。使用本项目产生的数据同步结果请自行核验，作者不对数据丢失负责。

> **🚀 首次使用建议**：先关闭「定时推送/定时拉取」开关，手动点一次 ⇅ 验证上传与拉取行为符合预期后，再开启定时。

## ✨ 功能特性

### 📤 上传（Obsidian → IMA）

- **全类型支持**：`.md` / pdf / word / ppt / excel / csv / 图片 / txt / xmind / 音频 / html / epub，按扩展名自动识别类型并校验官方大小上限
- **增量推送**：md 按正文 hash 记账、附件按二进制指纹，内容没变不重传
- **自动补传**：每次推送前批量核验服务端（50 个/批），你在 IMA 端删过的文件自动重新上传，无需手动清账本
- **同名自动编号**：IMA 官方 API 无更新/覆盖接口，远端同名被占用时自动编号为 `A(1).pdf`、`A(2).pdf`，旧版保留（即天然版本管理）
- **目录白名单**：只上传白名单目录下的文件，一个目录一行

### 📥 拉取（IMA → Obsidian）

- **多库多选**：设置页方框打勾复选列表，可同时勾选多个源知识库，拉取时逐库扫描汇总
- 把源知识库根目录的文件拉回本地指定文件夹（不存在自动创建）
- md 文本比对增量、其它类型二进制 md5 比对；**冲突保护**：同名但内容不同 → 跳过并报告，绝不覆盖本地修改
- 仅处理知识库根目录；IMA 客户端笔记/网页收藏类条目（无文件实体）自动过滤

### 🔀 方向开关（单向模式）

- 「启用上传」「启用拉取」两个独立开关，默认全开
- 关掉一侧即成**纯单向模式**：⇅ 自动跳过关闭的方向；命令面板单独调用也会被守卫拦下

### 🔄 双向同步

- 按传输策略串行执行两个方向：**先上传再拉取**（默认）或**先拉取再上传**
- 左侧竖栏「杨」字图标 / 右下角状态栏 `杨 ⇅` 按钮，**点一下全对齐**
- 运行中显示进度条 + 百分比 + 当前文件名，结束显示绿/红汇总 6 秒自动收起

### ⏰ 定时同步

- **定时推送**：每天到点自动把白名单目录上传到 IMA 知识库（默认 09:00，可自定义 HH:MM，可关）
- **定时拉取**：每天到点自动从 IMA 知识库拉取到本地（默认 21:00），当天只跑一次
- **到点/晚点都跑**：若设定时刻 Obsidian 未运行（睡眠/关机），当天晚些时候打开会补跑一次，不会静默漏掉；跨天不补
- 到点时若上一次任务仍在运行则自动让位跳过；「先落盘再执行」保证插件崩溃/重启不会同一天重复触发
- 设置页分别在「上传区」「拉取区」配置开关与时刻

### 🛡️ 稳定性设计

- 运行锁防并发（上传/拉取/同步互不打架）
- 服务端校验接口异常时自动降级为纯本地增量，不会卡死推送
- 前置校验齐全：未配 Key、白名单为空、未选知识库都会给出明确 Notice 提示

## 📦 安装

> 本插件未上架官方市场，需手动安装（或通过 BRAT 等社区方式）。

1. 下载 `main.js`、`manifest.json` 两个文件
2. 放到你的库目录：`<vault>/.obsidian/plugins/tencent-ima-sync/`（文件夹名必须与插件 id 一致）
3. Obsidian 设置 → 第三方插件 → 启用 **IMA 知识库同步**

> 从 v0.4.x（ima-push）升级：插件 id 已改为 `tencent-ima-sync`。新建上述文件夹放入新文件后，把旧 `ima-push/data.json` 原样拷进去即可保留全部配置。

## 🔑 获取 IMA OpenAPI 凭据

1. 前往腾讯 IMA 官方渠道申请 OpenAPI 的 **Client ID** 与 **API Key**
2. 插件设置页填入，点「测试连接」验证，再点「刷新知识库列表」拉取你有写入权限的知识库

## ⚙️ 配置说明

| 配置项 | 说明 |
|--------|------|
| Client ID / API Key | IMA OpenAPI 凭据，本地保存在 `data.json`，不会上传任何第三方 |
| 测试连接 | 验证凭据并顺带拉取知识库列表 |
| 刷新知识库列表 | 一键拉取当前 Key 有写入权限的全部知识库，供下拉框共用 |
| 传输规则 | 双向行为的完整说明（见设置页） |
| 远程目录（上传） | 白名单文件全部上传到这个知识库 |
| 启用上传 | 方向开关，关掉后 ⇅ 只拉取 |
| OB 端目录白名单 | vault 内文件夹名，一行一个，如 `【01-笔记】` |
| 远程目录IMA（拉取） | 方框打勾多选源知识库，拉取时逐库扫描 |
| 启用拉取 | 方向开关，关掉后 ⇅ 只上传 |
| 本地落地目录 | 拉取的文件存放的 vault 文件夹，留空 = 根目录 |
| 传输策略 | 双向同步的执行顺序，默认先上传再拉取 |
| 定时推送 / 时刻 | 每天到点自动上传白名单目录，默认 09:00，可关 |
| 定时拉取 / 时刻 | 每天到点自动从 IMA 拉取，默认 21:00，可关 |

## 🖱️ 使用方式

| 入口 | 位置 | 行为 |
|------|------|------|
| 「杨」字图标 | 左侧竖栏 | 双向同步（按传输策略） |

## ⚠️ 能力边界（务必了解）

1. **IMA 官方 API 没有「更新/覆盖已入库文件」的接口**——修改文件后再推送，IMA 端会新增 `A(1)` 版本，旧版保留；想要干净覆盖：先去 IMA 端删旧版 → 再推送
2. IMA 客户端笔记/网页收藏类条目（如网页剪藏，无文件实体）不支持拉取——OpenAPI 返回的是客户端内部协议地址而非文件链接（已实测）
3. 仅处理知识库根目录，子文件夹不递归
4. 插件 id / 目录名为 `tencent-ima-sync`，请勿中途改名（会丢失本地账本配置）

## 🔧 技术实现

- 鉴权：`ima-openapi-clientid` / `ima-openapi-apikey` / `ima-openapi-ctx` 请求头
- 上传链：`create_media`（获取 STS 临时凭证）→ 腾讯云 COS v5 签名直传（HMAC-SHA1）→ `add_knowledge` 入库
- 增量：本地 `fileStates` 账本记录每篇 pushHash / kbId / mediaId
- 服务端存在性校验：`check_repeated_names` 批量核对（50 个/批），`is_repeated=false` 视为远端已删除 → 自动补传
- 拉取链：`get_knowledge_list`（游标分页）→ `get_media_info`（签名 URL + 专用 headers）→ 带头 GET 下载原文
